## Lessons for Future Rebases (1.0.5, etc.)

1. **Use cherry-pick, not merge** — prevents "auto-resolution" disasters
2. **Enable git rerere** — `git config rerere.enabled true` (already done)
3. **Verify patches early** — grep for critical signatures before build
4. **Watch iCan changes** — upstream keeps hardening identity checks
5. **Keep Locale.US** — needed for TTS in de/fr locales
